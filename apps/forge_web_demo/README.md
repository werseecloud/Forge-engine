# Forge Web Demo

Planned browser target for the Forge Renderer WebGPU slice.

Current status:
- The renderer contracts use WGSL/WebGPU-compatible capability and settings types.
- Browser native hardware ray tracing is not assumed.
- A compute path tracing fallback is planned for Milestone 3.

Run target will be added when the renderer core is split into a WASM/WebGPU package.
