Forge AI Runtime
================

Place the local GGUF inference runner here for packaged Forge Engine builds.

Supported executable names:

- forge_ai_runner.exe
- llama-cli.exe
- llama-run.exe
- main.exe

Forge Engine passes:

- the selected GGUF model path
- a prompt file
- max token count
- temperature

No Ollama process or cloud provider is used by this runtime path.
